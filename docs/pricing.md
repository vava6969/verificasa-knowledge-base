# Pricing and monetization

VerifiCasa makes money through **monthly subscriptions**. Paid plans include all upgrades (for example, access to the 3D tour app).

| Plan | Price |
|---|---|
| Free | 0 RON / month |
| Basic | 35 RON / month |
| Pro | 50 RON / month |
| Agent | 89.99 RON / month |

## Payments

- Payments run through **Stripe**, which is being moved from a personal (PF) account to the company, **VERIFICASA SRL** (PJ).

## Other revenue ideas

- **Videographer partners page:** videographers are listed on VerifiCasa and referred clients for property videography. VerifiCasa takes a commission.
- **Virtual staging:** possibly **10 free stagings per month for renters**, funded by owner and agency subscription revenue.
