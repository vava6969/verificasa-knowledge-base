# Tech stack

| Area | Technology |
|---|---|
| Website | Standalone infrastructure (migrated off Base44, where it was first hosted as an app) |
| Mobile app | Swift / SwiftUI (iOS); Android version also planned |
| 3D scanning | ARKit + RoomPlan (LiDAR) |
| Image stitching | OpenCV + ARKit |
| Server | Own VPS: CPU-only, ~2 TB storage, used for panorama stitching and possibly self-hosted AI models |
| Virtual staging | Gemini 3.1 Flash Image API through a Base44 backend function |
| Prototypes / side apps | Base44: "VerifiCasa Tur 360°" (360° tours), "Virtual Staging AI" |
| Payments | Stripe (moving to VERIFICASA SRL) |
| Design | Figma (design system for the app redesign) |
| Marketing automation | Claude (scheduled agent), Composio (Instagram connection), Higgsfield (AI visuals and video) |
