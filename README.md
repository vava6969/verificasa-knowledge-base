# VerifiCasa

**Chirii verificate online. Fără surprize neplăcute.**
*(Verified rentals online. No unpleasant surprises.)*

VerifiCasa ([verificasa.ro](https://verificasa.ro)) is a Romanian real-estate platform for **verified rental and property listings**. It combines team-moderated listings, property-history checks, secure messaging and in-house 3D virtual tours. The long-term goal is to **digitalize the Romanian real-estate industry** and give agencies an all-in-one toolkit, similar to Matterport or CubiCasa.

- **Company:** VERIFICASA SRL (Romania)
- **CEO / founder:** Andrei Mocanu
- **Website:** https://verificasa.ro
- **Instagram:** [@verificasaro](https://instagram.com/verificasaro)
- **Status (Nov 2026):** website in testing and not yet public; iOS and Android app "coming soon"; no public listings yet; building an audience before launch
